# Структура проекта

Каждый экран имеет свою функциональную папку в `src/features`; в `src/app` находятся только маршруты.

| Маршрут | Компонент | Медиа |
| --- | --- | --- |
| `/` | `home/HomePage.tsx` | `public/home/` |
| `/menu-demo` | `menu/MenuShowcase.tsx` | `public/menu/images/` |
| `/molecules-demo` | `molecules/MolecularSection.tsx` | `public/molecules/images/` |

Главная делится на `hero`, `header`, `story` и `advantages`. Поиск/кабинет/корзина пока только UI без backend. Контакты, каталог и оформление заказа будут отдельными страницами, когда появится их логика.

Не перезаписывайте `main` без отдельного утверждения. Временные эксперименты удалены только из feature-ветки; исходный код сохранён в `backup/pre-refactor-2026-10-18`.

Локальные `oil.webm` и `fon2.webp` специально оставлены по старым путям, чтобы сборка не зависела от их незакоммиченного перемещения.

## Сцена преимуществ

`BrandStory` постепенно проявляет текст по буквам (с прописными буквами), перемещает логотип вправо примерно на середине текста и возвращает его после полного проявления. Не требуется прокручивать до нового блока: сама закреплённая сцена показывает `fon2.webp` и карточки `AdvantagesSection` после завершения обратного перелёта логотипа. Список семи карточек и явное соответствие WebP-файлам: `src/features/home/advantages/advantages.ts`.

**Не перемещать незакоммиченные файлы:** `public/home/images/icons/ico1.webp` — `ico7.webp`, `public/home/images/fon2.webp`, `public/home/video/oil.webm`. Они сохраняются локально после `git pull`.
